# stockDeck
Es una aplicación web de gestión de inventario y ventas, creada con el objetivo de facilitar el control de productos y movimientos de mercancía en pequeños negocios.

Este proyecto nace como una iniciativa personal para poner en practica conocimientos de desarrollo web y aprender a construir una aplicación desde cero, desde la interfaz hasta la logica del servidor y el almacenamiento de datos.

## Objetivos del proyecto
- Registrar productos
- Consultar y buscar productos
- Editar información de productos
- Eliminar productos
- Validar precios y cantidades
- Registrar ventas
- Controlar entradas y salidas del inventario
- Implementar usuarios con diferentes permisos

## Tecnologías
El proyecto contempla el uso de las siguientes tecnologías:
- HTML: estructura de la aplicación
- CSS: diseños y estilos
- JavaScript: logica e interactividad
- Node.js y Express: desarrollo del servidor
- PostgreSQL: almacenamiento y gestión de datos
- Git y Github: control de versiones

Estas se irán incorporando conforme avance el desarrollo.

## Estado del proyecto
Actualmente el proyecto se encuentra en etapa inicial del desarrollo. Se está trabajando la estructura HTML y en la construcción de la interfaz de inventario.

## Objetivo de aprendizaje
StockDeck también funciona como un proyecto de aprendizaje y práctica. El desarrollo se realizará progresivamente, priorizando la comprensión de cada herramienta y la resolución de problemas durante el proceso.
